Local Pipeline Guide / Candidate Review Area

Source Intelligence Workbench

Read-only visibility for the SEC ingestion pipeline. This workbench shows the safe local workflow, scheduled preview plan, candidate-only files, and review boundaries; it is not production graph data and not live backend automation yet.

READ ONLY LOCAL TERMINAL COMMANDS NOT GRAPH DATA NO BROWSER SCRIPT RUNNER
How to Run Locally

Open PowerShell, cd to the repo root, then run one command at a time. The repo root contains index.html, data/, and scripts/.

SEC USER-AGENT

Network-enabled SEC commands need a real contact string. The user-agent is not an account and does not email you; it identifies the script politely to the SEC. Example: "Name User@Email.com".

Pipeline Overview

The system turns reviewed SEC inputs into candidate files, then uses promotion preview, manual promotion, and validation before any production graph change.

schedule plan -> reviewed job -> SEC lookup/cache -> filing plan/fetch -> signal extraction -> candidate files -> promotion gate -> validation

Recommended Workflow

This is the bulk-first local path for generating SEC candidates safely.

Browser displays commands only.
Scheduled Preview -> Reviewed Job Plan -> Bulk Candidate Generation -> Promotion Preview -> Manual Promotion -> Validation
1. Scheduled Preview 
python scripts/sec_scheduled_run_preview.py --schedule-id weekly_mega_cap_core_preview --include-commit-plan
2. Bulk Candidate Generation 
python scripts/sec_bulk_pipeline_run.py --tickers AAPL,MSFT,NVDA,AMZN,GOOGL,META,AMD,INTC,AVGO,JPM,GS,BLK,XOM,CVX,UNH,LLY,GE,CAT --forms 10-K,10-Q,8-K --limit 10 --allow-network --user-agent "Name User@Email.com" --write-candidates --force

Preferred candidate generation path. Use tickers from the approved ticker/CIK universe or reviewed jobs; output remains candidate-only, and promotion still requires preview, manual promotion, and validation.

3. Promotion Preview 
python scripts/sec_candidate_promotion_preview.py
4. Manual Promotion 
python scripts/sec_candidate_promote.py
5. Validation 
python scripts/validate_data.py

Scheduled Preview

Previews cadence, the next job command, candidate generation, policy gate, validation, and optional commit plan. It does not execute scheduled jobs.

Reviewed Job Runner

Optional manifest path for reviewed jobs such as mega_cap_core or batch_1_multi_sector. It delegates reviewed bulk runs; the main path remains bulk candidate generation.

Bulk Runner

Generates review-only SEC relationship candidates from approved ticker/CIK mappings. Network access and candidate writes require explicit flags.

Safety Notes
  • No backend or browser script runner is added.
  • The browser does not call SEC directly.
  • Candidate files are review-only and not production graph data.
  • Broader coverage comes from approved mappings and reviewed jobs.
  • Production promotion stays manual, previewed, policy-gated, and validated.
